# fredx 标准文档

**crate**：`fredx` v0.1.0 | **来源**：`specs/adapter/fred.md`（source_id = `fred`）| **状态**：非 package stable

**能力标准**：本库以类型化形式表达 FRED 源事实，并提供离线解析、跨源守卫与 fail-closed
授权判定。**它不是联网采集器**，不实现 live/PIT，`production_decision = NO-GO`。

## 1. 源事实与采集范围标准

- 采集集合 = 清单明确列出的 **35 个纯 FRED series ID**，分为五组：
  P0 组 13（`DFII10` `T10YIE` `BAMLH0A0HYM2` `T10Y2Y` `ICSA` `WALCL` `WTREGEN` `RRPONTSYD`
  `SOFR` `DFF` `VIXCLS` `SP500` `DCOILWTICO`）、利率与曲线组 4（`DGS2` `DGS10` `T5YIFR`
  `TEDRATE`）、经济基本面组 4（`PCEPILFE` `UNRATE` `PAYEMS` `CES0500000003`）、
  全球与区域组 12（`DEXJPUS` `IRLTLT01JPM156N` `JPNCPIALLMINMEI` `DEXUSEU` `CPHPTT01EZM659N`
  `FYFSGDA188S` `FDHBFRBN` `BOGZ1FL662090005Q` `NASDAQCOM` `NIKKEI225` `PCOPPUSDM` `DEXCHUS`）、
  BLS 转发闭合组 2（`CPILFESL` `JTSJOL`）。
- `WRESBAL` 为 **mapping-only**：登记在案、接受映射，但**不进采集集合**；它只因写入主权而被登记。
- `BAMLC0A0CM` **已 drop**，MUST NOT 视为可用系列；`RESPPLLOPNWW` 为归属未决候选。
- 清单未列出的 series ID MUST NOT 被本库接受（`ensure_known_series` 原子拒绝）；
  `FDHBFRBN`「等」的全集未钉死，本库 MUST NOT 自行扩集。
- `GDPNow` 的载体为 `absent`（待 Owner 钉死），本库 MUST NOT 用 `GDP` 顶替。

## 2. 值与期间标准

- `Date { year: i16, month: u8, day: u8 }`：年份 `1..=9999`、月 `1..=12`、日按月份与闰年校验。
- `Period`：`Day` / `Month` / `Quarter` / `Year` / `Event`；`quarter` ∈ 1..=4。MUST NOT 用字符串顶替。
- `Frequency`：`daily` `weekly` `monthly` `quarterly` `annual` `event` `irregular` 七个记号，
  **只接受小写**。
- 值形态 `FredValue`：`Present(f64)` 或 `Missing(FredMissingReason)`；缺失 MUST 具名表达，
  MUST NOT 静默折算为 `0`。`Present` 的值 MUST 为有限数（NaN / 无穷被拒绝）。
- 观测 `FredObservation`：身份 = `series_id` + `period` + `vintage`；`vintage` 无官方面时为 `None`，
  MUST NOT 伪造。
- 公开校验入口：`validate_date` / `validate_period` / `validate_observation`。

## 3. 单位与不换算标准

- 本库**保留源单位**，MUST NOT 在源层做任何单位换算（换算归下游 Normalize）。
- 清单已声明源单位的序列：`WALCL` / `WTREGEN` = `Millions of U.S. Dollars`，
  `RRPONTSYD` = `Billions of U.S. Dollars`。两者**量级不同**，MUST NOT 视为同一单位。
- `ensure_source_unit` 对已声明单位的序列做一致性判定：不符则 `SemanticallyRejected`，
  且**只拒绝、不换算**（值本身不被改写）。
- 清单未声明源单位的序列不做该判定（`series_unit` 返回 `None`）。

## 4. 跨源守卫标准（近义非同 ID / BAML 冻结令）

- `NEAR_SYNONYM_PAIRS` 登记 `cross-source-routing.md` §4 中**涉及 fred 的 14 对**
  近义非同 ID：`DFF`≠`EFFR`、`SP500`≠`SPY`、`DCOILWTICO`≠`CL=F`、`PCOPPUSDM`≠`HG=F`、
  `GDPNow`≠`GDP`、`PCEPILFE`≠`PCEPI`、`CPILFESL`≠`CPIAUCSL`、`NASDAQCOM`≠`QQQ`、
  `NIKKEI225`≠`EWJ`、`DEXCHUS`≠`USDCNH`、`DX-Y.NYB`≠`DTWEXBGS`、`T20100`（BEA 表内 PCE 行）≠`PCEPILFE`、
  `^TNX`≠`DGS10`、`RESPPLLOPNWW`≠`WRESBAL`。
- `ensure_not_silent_substitution` 对该表**双向**判定：命中即 `SemanticallyRejected`，
  MUST NOT 互为别名或静默替换。
- **BAML 冻结令**：本库只允许 `BAMLH0A0HYM2` 一个 BAML 系列。其它 `BAML*` 一律
  `SemanticallyRejected`；`BAMLC0A0CM` 已 drop，恢复须 Owner 书面豁免。

## 5. 写入主权与曲线边界标准

- `AUTHORITATIVE_WRITE_SERIES = [WALCL, WTREGEN, RRPONTSYD, WRESBAL]`：这四条的权威
  Observation **唯一写入方**为本域（Owner 联裁 `WALCL-AUTHORITY-2026-08-20-A`，选项 A）。
  其它源只可对账告警，MUST NOT 覆盖权威值、MUST NOT 双写 canonical key。
- `claim_authoritative_write` 是**只读判定**：仅上述四条返回 `Ok`；其余一律
  `WriteAuthorityDenied`，并区分三种理由——曲线点权威归 `yieldx`、BEA 表号归 `beax`、
  未决候选归属不明。判定 MUST NOT 改写任何登记值。
- **曲线边界**：`DGS*` / `T10Y*` 是曲线**输入点**，本库可持有其源观测；
  **曲线构建归 `yieldx`**（`CURVE_BUILD_OWNER`）。`ensure_product_local(FredProduct::YieldCurve)`
  一律返回 `RoutedElsewhere`，MUST NOT 在本域洗白为曲线权威。
- 本库 MUST NOT 另开 NY Fed 产品模块，也 MUST NOT 把 H.4.1 写成 FRED series ID；
  treasury FD01–FD04 是永久**校验面**（只告警）。

## 6. publication 语义标准

- `fred_publication_semantics()` 恒返回 `(Date, Inferred, NotEligible)`。
- `is_formal_pit_eligible()` **恒为 `false`**（对应清单的
  `macro_fred::assemble_fred_observations` 口径）：FRED 标准 API 的 `realtime_start`
  语义为日期而非时刻，离线 fixture 无 ALFRED vintage，属推断层。
- MUST NOT 补造 `00:00 UTC` 之类时刻把 `Date` 伪装成 `Instant`；正式 PIT 路径须走 ALFRED vintage。
- 日后若接入官方 vintage 或经签批的发布日历，MUST 先改清单与契约，**禁止静默升格**。

## 7. 授权判定标准（fail-closed）

- 已登记证据：`FRED-PROD-2026-08-15-approve`（签署者 `ZoneCNH`），覆盖**offline 范围**。
  同一 receipt 登记 `live = no-go`，故 `FredAccessMode::Live` **不被覆盖**。
- `authorize_fred` 的判据：证据缺失 / 签核编号不明 / 签署者不明 / 覆盖范围不明 / 已过期 /
  请求模式不在覆盖集合内 → **一律 `Denied`**，MUST NOT 默认放行。
- 判定 MUST NOT 改写清单原登记值；判定的是「该源的这个范围是否被授权访问」，
  **不是**「本库是否生产就绪」。
- 评估日期 `as_of` 由调用方传入，本层**不读取系统时间**。

## 8. 离线解析标准

- 入口 `parse_fred_observations(input: &str)` **只接受字符串**，MUST NOT 接受 URL、
  HTTP 客户端、认证信息或任何网络参数。
- 输入形态为本库自定的 JSON 对象：`{ "_synthetic"?, "_note"?, "records": [ … ] }`，
  每条记录 `{ series_id, date, value, unit, frequency, vintage? }`。`_synthetic` / `_note`
  是**已知字段**（合成样本标注），不是未知字段。
- **未知字段原子失败**（顶层或记录层出现未知键 → 整体失败，MUST NOT 静默忽略）。
- **重复身份选择「拒绝」**（不去重）：同一 `(series_id, period, vintage)` 出现两次即
  `SemanticallyRejected`。
- 值形态：JSON 数值 → `Present`；`"."` 或 `null` → `Missing(NoObservation)`；其余 → 拒绝。
- 期间投影：按清单频率把源日期投影为该频率的期间身份（日/周/不规则 → `Day`；
  月 → `Month`；季 → `Quarter`；年 → `Year`；事件 → `Event`）。这是**期间投影**，不是派生指标。
- 解析错误消息只报告行列位置，MUST NOT 回显输入内容。

## 9. 合成夹具声明

`tests/fixtures/` 下的全部夹具（`fred_observations_synthetic.json`、
`fred_missing_value_synthetic.json`）都是**合成样本**：由特性 005 自拟，**不是真实源数据，
不构成任何证据**，MUST NOT 被表述为「实测」「核验 PASS」或任何证据等级。每个夹具文件在
顶层带 `"_synthetic": true` 与 `"_note"` 标注。清单未声明源单位的序列，其 `unit` 取值是
**合成占位串**，不得当作源单位事实。

## 10. 依赖与零网络标准

- 依赖仅 `thiserror` / `serde`（`derive`）/ `serde_json`；
  MUST NOT 引入任何 HTTP 客户端、异步运行时、`chrono` / `time`、`rand`。
- 源码 MUST NOT 出现 `https://…` 端点字面量，MUST NOT 读取环境变量或凭据，
  MUST NOT 配置代理。
- MUST NOT 依赖任何 `bytechainx/*` crate（含 `path` 依赖）；本库与兄弟库的形状**各自实现一遍**，
  MUST NOT 新建共享 core crate。
- 非测试路径 MUST NOT 出现 `unwrap()` / `expect()` / `panic!` / `println!` / `dbg!`。
